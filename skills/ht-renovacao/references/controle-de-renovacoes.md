# Planilha de controle de renovações

Modelo de referência: planilha com a aba "ACOMPANHAMENTO RENOVAÇÃO",
vazia, sem fórmulas, com duas validações de lista (E3:E1001 e I3:I1001; conferido no arquivo). Linha 1: rótulo do bloco D-G ("gestão das confirmações de presença e feedbacks") e do bloco H-J ("gestão de
renovações"). Linha 2: cabeçalho.

| Col | Campo | Valores (padrão do squad quando a fonte não define) |
|---|---|---|
| A | Nome | |
| B | E-mail | |
| C | Turma | |
| D | Confirmou presença? | Sim / Não / Sem resposta |
| E | Temperatura | lista do modelo: Satisfeito / Neutro / Insatisfeito |
| F | Feedback | resumo do 1 a 1 e do formulário (o que trouxe de bom, de ruim, dificuldade) |
| G | O que faria de diferente? | |
| H | Está presente? | Sim / Não (preenchido no dia) |
| I | Status Renovação | lista do modelo: Em aberto / Renovado (pintar de verde) / Não vai renovar |
| J | Comentários | quem abordou, quando, objeção, próximo passo |

Colunas extras sugeridas pelo squad (marcar como acréscimo): Elegível a upgrade? · Responsável pela abordagem · Data da última
abordagem · Valor fechado (preenchido pelo financeiro, não pelo agente).

Uso:
- Antes: todos os aptos, inclusive quem não confirmou; filtro por "Confirmou".
- No evento: planilha aberta na salinha (tela maior se houver); cada abordagem anotada ("já falei com fulano"), para ninguém ser
  abordado duas vezes nem esquecido.
- Depois: filtro "Está presente? = Não" ou "Status = Em aberto" → lista do pós-evento.
- Indicadores para o ht-controller: confirmados/aptos, presentes/confirmados, renovados/aptos, renovados/presentes,
  renovados/ausentes, renovados por temperatura (satisfeito, neutro, insatisfeito).
