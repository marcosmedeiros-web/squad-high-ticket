# LDP: modelos das peças (estrutura do método, redação do squad)

A redação abaixo é do squad, seguindo a ordem e os elementos do método. Tudo entre colchetes vem do expert ou de `02-oferta/`. Nada de frequência, número ou história inventados: se o expert não
recebe pedidos "todo dia", o texto diz a frequência real. Revisar sempre com `avoid-ai-writing` ou `humanizer` e na voz do expert.

## 1. Promessa (vai em todas as peças)

Os 7 elementos obrigatórios: (1) data e hora · (2) "live direto ao ponto para apresentar" + nome do programa ·
(3) "acompanhamento individual" · (4) definição de resultado do AR · (5) vagas limitadas · (6) chance de aplicar ou
condição especial · (7) sem gravação e sem replay.

```
Dia [DATA], às [HORA], faço uma live direto ao ponto para apresentar o [PROGRAMA],
meu acompanhamento individual para [AVATAR] que querem [DEFINIÇÃO DE RESULTADO DO AR].
São poucas vagas, e quem estiver ao vivo vai poder [aplicar / entrar com uma condição que só existe nessa live].
Não fica gravada. Não tem replay.
```

## 2. Convite por e-mail, narrativa do herói relutante (padrão)

Ordem: pedido frequente (frequência real, na linguagem do avatar) → relutância (motivo real, o mesmo da sessão 1a1) → o que
mudou → decisão de abrir para poucos → promessa → link → filtro ("não é para curioso") → assinatura.

```
Assunto: Quer que eu acompanhe você de perto?
(variações: "Quer que eu trabalhe pessoalmente no seu [negócio / carreira / objetivo]?")

[Nome], [com que frequência real] alguém me escreve pedindo [o pedido, nas palavras do avatar].
Por muito tempo eu disse não, porque [motivo real da relutância].
Aí [o que aconteceu de fato e mudou a decisão].
Decidi abrir um acompanhamento individual para um grupo pequeno.

Dia [DATA], às [HORA], vou fazer uma live direto ao ponto e apresentar o [PROGRAMA]:
como funciona, o que está incluído e quanto custa.

[LINK DE CADASTRO]

Se você está só curioso, não precisa se cadastrar.
Se quer alguém do seu lado corrigindo a rota até [RESULTADO], te vejo lá.
[Assinatura]
```

**WhatsApp individual e de grupo**: mesma ordem, 4 a 6 linhas, link no fim. No grupo, a mensagem fixada na entrada repete
promessa, data e hora.

## 3. Convite por e-mail, narrativa da oferta indecente (só com janela real)

Ordem: exclusividade do público (aluno, cliente, quem foi ao evento) → a janela que existe agora e por quê → condição que de
fato não existiu antes → vagas por ser individual → sem replay → link → linguagem diretiva (não dizer que é conteúdo).

```
Assunto: Uma condição que só vou abrir para quem já me conhece
(variação mais direta: "Oferta indecente para você")

Este convite é só para [quem é aluno / cliente / participou de EVENTO].
Dia [DATA], às [HORA], vou abrir a entrada no [PROGRAMA] [fora do período normal / numa turma nova / com as vagas que
sobraram], com [a condição real, descrita sem exagero].
As vagas são poucas porque o acompanhamento é individual. A live não fica gravada.

[LINK]

Na live eu mostro como funciona e o preço. Se fizer sentido, você já entra.
```

## 4. Roteiro do criativo (um basta)

Herói relutante, 40 a 60 s: contexto de quem assiste ("se você me acompanha aqui...") → pedido frequente → relutância e motivo
→ o que mudou → data, hora e "live direto ao ponto para apresentar o [PROGRAMA]" → permissão para ignorar → CTA de cadastro com
filtro ("não entre por curiosidade").

Oferta indecente: "você está entre as pessoas que estou convidando" → a janela → data, hora, o que será revelado (condição,
funcionamento, preço) → vagas limitadas, sem replay → CTA.

Compliance Meta (passa pelo ht-revisor-metodo-copy): sem promessa de renda garantida, sem atributo pessoal ("você que está
endividado"), sem antes e depois. Nomenclatura da campanha com o prefixo de campanha do perfil (`trafego.prefixo_campanha`), se houver; nasce PAUSADA.

## 5. Página de captura (genérica, sem narrativa)

```
TÍTULO: [PROGRAMA]: live direto ao ponto, [DIA] às [HORA]
SUBTÍTULO: Meu acompanhamento individual para [AVATAR] que querem [RESULTADO]. Na live eu mostro como funciona.
3 CONDIÇÕES (ícones): Vagas limitadas · Sem gravação · [Chance de aplicar / condição especial ao vivo]
BIO CURTA: foto + 2 a 3 linhas de credencial ligada ao resultado que o expert gera (prova é opcional)
BOTÃO: Quero me cadastrar
ABAIXO DO BOTÃO: É uma live de apresentação da oferta. Se você está só curioso, não se cadastre.
```
Fluxo: botão → pesquisa (seção 6) → grupo de avisos. Sem página de obrigado. Pixel: evento Lead no envio da pesquisa.

## 6. Pesquisa de cadastro (curta; entre o botão e o grupo)

```
Nome · e-mail · WhatsApp (pedir de novo para casar a resposta com a pessoa)
1. O que fez você se cadastrar nesta live?                         [aberta: desejo na voz do avatar → narrativa]
2. Qual é seu maior desafio hoje para [RESULTADO DO AR]?           [aberta: dor → bloco da oportunidade]
3. O que descreve você hoje?                                       [nível de consciência]
   ( ) Já sou aluno/cliente  ( ) Já comprei algo seu  ( ) Acompanho, nunca comprei  ( ) Te conheci agora
4. Quanto você quer este acompanhamento?                           [intenção → ordem da recuperação]
   ( ) Quero muito uma vaga  ( ) Tenho interesse, quero entender  ( ) Só quero conhecer
→ botão "Entrar no grupo de avisos"
```
Leitura: muita gente em "te conheci agora" é sinal de formato errado (alertar a pessoa). Pergunta 4 ordena a recuperação.

## 7. Lembretes (cadência do método; textos são rascunho do squad)

| Toque | Canal | Função | Rascunho |
|---|---|---|---|
| Entrada | grupo (fixada) | situar | "Este é o grupo de avisos da live do [PROGRAMA], [DIA] às [HORA]. Vou apresentar meu acompanhamento individual para quem quer [RESULTADO]. O link sai aqui." |
| Véspera | grupo + e-mail 1 | lembrar e filtrar | "Amanhã, [HORA]: apresento o [PROGRAMA] e abro as vagas. É só ao vivo." |
| Manhã | grupo | compromisso | "Hoje às [HORA]. Separe [duração] sem interrupção." |
| 1 h antes | grupo | preparar | "Daqui a 1 hora. Link: [LINK]. Entre pelo computador se puder." |
| Na hora | grupo + e-mail 2 | entrar | "Começou: [LINK]." |
| +10 min | grupo | resgatar | "Já estou apresentando como funciona o [PROGRAMA]. Ainda dá tempo: [LINK]." |

WhatsApp individual é opcional na mesma cadência. Disparo só com OK da pessoa e pela regra do canal (API oficial para massa a
cliente; nunca número pessoal do expert).

## 8. Formulário de aplicação (instrumento de seleção)

```
Nome · e-mail · telefone (de novo)
1. Descreva seu [negócio / momento].
2. [Faturamento atual ou o marco de resultado do nicho: nº de clientes, formação, resultado já gerado].
3. Por que você está comprometido a entrar agora?
4. Que resultado você espera do acompanhamento? (alinha expectativa)
5. As vagas são poucas: por que deveríamos escolher você?
→ fim: link de pagamento da aplicação (se paga) ou agenda/WhatsApp (se grátis)
```
Perguntas abertas; resposta curta e vazia é sinal de recusa. Adaptar ao avatar; só perguntar o que entra na avaliação.
